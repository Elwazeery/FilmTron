# FilmTron — TRON Local Creative AI Integration and Direction

**Status:** DOCUMENTATION / PROPOSED, no local model/agent functionality or real creative result verified. This is the 2026-10-21 owner's explicit amendment to the older "no local AI" design: ONE optional TRON local creative agent is allowed, but no bundled models, mandatory AI, paid API or independent cloud MCP service. ChatGPT remains the primary director and can either execute via the existing GemiMCP product tools or delegate bounded jobs to TRON. Shared identity, persona, data policy, model lifecycle, cloud delegation and creative rulebook live in **GemiTron88/GemiMCP**, not cloned into every product.

Links: [Hybrid ADR](https://github.com/GemiTron88/GemiMCP/blob/main/docs/architecture/07-LOCAL-CREATIVE-AI-HYBRID-20261021.md) · [TRON persona/training](https://github.com/GemiTron88/GemiMCP/blob/main/docs/creative-ai/TRON-PERSONA-AND-TRAINING-STRATEGY.v1.md) · [Creative knowledge](https://github.com/GemiTron88/GemiMCP/blob/main/docs/creative-ai/CREATIVE-KNOWLEDGE-AND-WORKFLOWS.v1.md) · [Delegation contract](https://github.com/GemiTron88/GemiMCP/blob/main/contracts/CREATIVE-AI-DELEGATION.v1.md).

**Runtime lifecycle:** Start model only when user explicitly activates Local AI tab (opt-in, never on app launch). Every tab holds scoped lease of ONE shared on-device model; closing tab releases own lease and closing/crashing editor releases all its leases. Model unloads after last lease and bounded active job drain, NOT while another product's tab or approved job uses it. Cloud ChatGPT delegation never causes covert model auto-load/download or indefinite residency. RTX 3050 6GB/64GB RAM baseline; model Qwen3.5 4B quant for INFERENCE benchmarking; no claim of GPU fit with full native preview. ChatGPT delegation requires exact app/device/project/revision, verified user consent, scopes and real receipts. Offline editing always works. Persona is *TRON*, natural Egyptian Arabic Gen Z in conversation, but exported creative assets obey user-requested target language/market. No fine-tuning required for phase 1; do not assume Qwen3.5 4B QLoRA fits 6GB (current Unsloth explicitly cautions against Qwen3.5 4-bit QLoRA; BF16 LoRA 4B ~10GB VRAM).

## Editorial knowledge overlay v1
1. **Editorial plan:** audience, hook, action, 3-act beat sheet, short shots selected from real media; avoid hallucinated content.
2. **Frame correctness:** rational frame/timebase, source-in/source-out vs timeline range, frame-precise cuts, VFR and music sync. No silent millisecond rounding.
3. **Color/audio:** conservative grading via real scopes, neutral shot match, dialogue-first mix with real meters, safe music ducking; never pretend to transcribe audio without available ASR.
4. **Titles/captions:** regional language is brief-controlled (TRON conversation Egyptian only), RTL Arabic shaping and safe read-time; actual transcript/timecodes required.
5. **Golden journey:** 15-second mobile ad with two sources, licensed music, actual CTA -> native cut edits -> readback of timebase/audio -> real frame previews -> native save/reopen, undo and verified decoded MP4 + model unload; ChatGPT direct tool unchanged.

## TRON UI and agent flows
An optional Creative AI tab in FilmTron shows clear **ChatGPT / TRON Local / Manual** modes (ChatGPT may require internet), model state, lease, resource estimate, user consent, preview, plan/diff, Execute/Approve/Pause/Cancel/Unload and receipts. Closing tab/app releases its leases and never unloads another program's active model. ChatGPT direct MCP control remains fully independent of TRON and keeps existing cloud auth, grants, GemiGuard and receipts. ChatGPT delegated calls use new `creative_ai.*` orchestration only after explicit consent. No model auto-download, no need to run a background AI server when no session, no separate model per app.

## Domain execution loop
Inspect actual state/current capability manifest -> create short nonlinear video editor plan referencing stable native IDs and expected revision -> native validate/dry-run diff -> consent/risk approval -> smallest edit batches -> real readback and actual screenshot/frame/audio analysis -> <=2 bounded refinements -> actual save/reopen/export when requested -> preserve undo and report real receipt. Distinguish user-visible TRON Egyptian dialogue from the locale of generated content; honor native color/alpha/audio and licensing. Never execute scripts generated by LLM, arbitrary filesystem/shell commands or writes outside allowed project. A model-proposed tool not present in catalog must fail UNSUPPORTED, not be auto-provisioned.
